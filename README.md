# python-quiz-game
#  FY IT Tech Quiz 

An interactive terminal-based quiz game built in Python, designed for First Year 
Information Technology students at KJ Somaiya College of Engineering.

## Topics Covered
- Python Programming
- Java & OOP Concepts
- C Programming
- HTML & CSS
- Networking & OSI Model
- Data Structures
- Computer Basics & OS

## Features
- 25 questions randomly shuffled every game
- 3 difficulty levels — Easy (10), Medium (15), Hard (25)
- Topic-wise score breakdown after every game
- Grade system — S / A / B / C / D based on percentage
- Revision mode — review all wrong answers at the end
- Play again option without restarting

## How to Run

### Option 1 — Online (No installation needed)
1. Go to onlinegdb.com
2. Change language to Python 3
3. Paste the code from quiz_game.py
4. Click Run!

### Option 2 — On your computer
Make sure Python 3 is installed, then:
python quiz_game.py
